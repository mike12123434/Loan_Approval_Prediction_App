# 貸款風險評估系統 - 優化重構版

## 🎯 改進重點

### 1. **使用合理的數學公式訓練利率模型**
- ✅ 利率 = 基礎利率 + 信用評分影響 + 負債比影響 + 貸款金額影響
- ✅ 利率範圍限制在 2.5% - 12.0%
- ✅ 基於真實金融邏輯，而非隨機數

### 2. **完整的模型訓練與評估**
- ✅ Train/Test Split (80/20)
- ✅ 計算準確率、精確率、召回率、F1、AUC-ROC
- ✅ 混淆矩陣分析
- ✅ 5折交叉驗證
- ✅ 特徵重要性分析

### 3. **使用 joblib 保存和載入模型**
- ✅ 訓練一次，重複使用
- ✅ 保存分類器、迴歸器、編碼器
- ✅ 保存模型評估指標和最佳閾值
- ✅ 大幅提升啟動速度

### 4. **避免 LabelEncoder 失敗**
- ✅ 預先定義所有可能的類別值
- ✅ 安全的 transform 函式處理未知值
- ✅ 使用預設值處理異常情況

### 5. **基於數據驗證的規則與閾值**
- ✅ 使用 ROC 曲線找最佳閾值（Youden's J 統計量）
- ✅ 規則基於訓練數據的統計分析
- ✅ 可選擇純 AI 模式或混合模式

## 📁 檔案結構

```
loan-risk-system/
│
├── config.py                      # 配置文件（常數、參數）
├── model_trainer.py               # 模型訓練與評估
├── assessment.py                  # 評估邏輯模組
├── app_LoanRisk_optimized.py      # Streamlit 主應用程式
│
├── loan_approval_dataset.csv      # 訓練數據（需自行準備）
│
└── models/                        # 模型保存目錄（訓練後自動生成）

    ├── label_encoders.pkl         # 編碼器

```

## 🚀 使用方式

### 步驟 1: 準備數據

確保 `loan_approval_dataset.csv` 檔案存在，並包含以下欄位：
- `loan_status` (核准狀態)
- `income_annum` (年收入)
- `loan_amount` (貸款金額)
- `cibil_score` (信用評分)
- `education` (教育程度)
- `self_employed` (就業狀態)
- `residential_assets_value` (住宅資產)
- `commercial_assets_value` (商業資產)
- `luxury_assets_value` (奢侈品資產)
- `bank_asset_value` (銀行資產)
- `loan_term` (貸款期限)
- `no_of_dependents` (扶養人數)
